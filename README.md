
# MIKU.EXE — Digital Diva Archive

## Project Description

MIKU.EXE is a multi-page website inspired by Hatsune Miku. The website introduces Miku's profile, history, fun facts, and selected songs through a colorful interface inspired by internet culture.

This project was created for a Web Programming course to practice HTML, CSS, and JavaScript.

## Features

- **Home Page:** Introduces the website and its digital-inspired theme.
- **About Page:** Presents Hatsune Miku's profile, history, and fun facts.
- **Music Page:** Displays a music archive where users can select tracks and play available audio files.
- **Interactive Theme:** Allows users to switch between light and dark themes.
- **Random Message:** Displays a randomly selected system message.
- **Music Notes Form:** Allows visitors to submit their favorite track and a short comment.
- **Responsive Design:** Adjusts the layout for different screen sizes.
- **Retro Y2K Design:** Uses colorful styling, background images, and digital-inspired elements.

## Technologies Used

- HTML5 — Website structure and content.
- CSS3 — Layout, colors, backgrounds, animations, and responsive design.
- JavaScript — Button interactions, theme switching, track selection, audio playback, and form validation.

## How to Run the Website

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Navigate between the Home, About, and Music pages.

For development, a local server such as the VS Code Live Server extension can also be used.

## How to Use

1. Open the Home page to explore the introduction.
2. Visit the About page to learn about Hatsune Miku.
3. Open the Music page and select a track.
4. Use the audio player to play available audio files.
5. Try the theme switcher and random message button.
6. Submit a music note using the form.

## Notes

- Background images and audio files must be placed in their corresponding folders.
- File names and paths must match the references in the HTML, CSS, and JavaScript files.
- Audio playback requires valid audio files and may depend on browser support.
- The music archive is intended for educational and non-commercial use. Only distribute audio files that you have permission to use.
